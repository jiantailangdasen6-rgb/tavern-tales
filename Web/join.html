------

ブラウザで入るとき
パソコンの Chrome・Edge・Firefox で開いてください（初回の読み込みは 1〜2 分。2 回目からは速くなります）。部屋を作れるのは Windows 版だけです。
Windows 版が開かないとき
ゲームを起動して「友人の部屋に入る」を押し、上のコードを入れてください。
一度ゲームを起動した PC なら、次からはこのページからそのまま開けます。
Windows 版を持っていないとき
いまの版（0.2.0）の Windows 版はまだ配っていません。上の「ブラウザで部屋に入る」から入ってください。 ダウンロードのページにある古い版（0.1.x）では、今の部屋に入れません。
