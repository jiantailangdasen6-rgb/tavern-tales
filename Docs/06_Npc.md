# NPC の扱い（2026-10-19〜）

方針は `Docs/05_Freedom.md` と同じ: **数字はゲームが持ち、AI は決まった選択肢から選ぶ**。
NPC の気持ちは AI の気分ではなく「態度」の段で決まり、頼みごとの難しさは表で決まる。

今の設定表の NPC は id・名前・立ち絵・居場所・役だけ（`NpcDef`）。以下を足す。

**決定（2026-10-19）**: 態度は 5 段。仲間の NPC は同時に 2 人まで。倒れた仲間の NPC の生死は運命のダイス（ありそう）。
1〜6 の残りの数字は案（試遊で調整）。7 の「時計」と「評判」は相談中。

## 1. 設定表に書く NPC の項目
| 項目 | 中身 |
|---|---|
| 名前・立ち絵・居場所・役 | 今あるもの（役: 依頼人 / 情報屋 / 黒幕 / 被害者 / 端役 など） |
| 口調 | 1 行（AI が語り分ける） |
| 望み・恐れ | 1 行ずつ。望みを叶えると態度が上がる、恐れは脅しの材料 |
| 知っていること | 手がかりの id。話してもらうと手に入る |
| 秘密 | 1 行と、聞かれたら嘘をつくか |
| 態度の初期値 | 下の 5 段から |
| 同行 | 喜んで / 条件付き（条件を 1 行）/ 来ない（理由を 1 行） |
| 戦闘の型 | 弱い / 普通 / 強い と、得意な能力値 1 つ、役目（攻め / 守り / 癒し） |
| 裏切り | なし / あり（引き金を 1 行） |
| 死んだら | 知っていることと役目を誰が引き継ぐか（G 項目 12） |

## 2. 態度（5 段、ゲームが持つ）
敵対 / 警戒 / 中立 / 友好 / 信頼

### 頼みごとの難しさ（態度 × 頼みの大きさ）
| 態度 | 小さな頼み（道や噂を聞く） | 普通の頼み（物を借りる、人に会わせる、知っていることを話す） | 大きな頼み（同行、危険を冒す、秘密を話す、主を裏切る） |
|---|---|---|---|
| 敵対 | 難しい | 至難 | できない（まず態度を変える） |
| 警戒 | 普通 | 難しい | 至難 |
| 中立 | 判定なし | 普通 | 難しい |
| 友好 | 判定なし | 易しい | 普通 |
| 信頼 | 判定なし | 判定なし | 易しい |
- 判定の能力値は頼み方で決まる: 頼む・説得する = 心、脅す = 力、言いくるめる・騙す = 知。
- 望みに沿う申し出や贈り物を添えると 1 段易しく（G8 の「有利」）。
- 脅しは成功すると従うが、態度が 1 段下がる。

### 態度が変わるとき（理由は決まった一覧から AI が選び、段の数はゲームが決める）
| 理由 | 変化 |
|---|---|
| 命を救う | +2 |
| 望みを叶える | +1 |
| 機嫌を取る・説得する（心の判定。成功 +1、大成功 +2、大失敗 -1） | ±1〜2 |
| 贈り物（1 人に 1 晩 1 回） | +1 |
| 嘘がばれる | -1 |
| 脅す（成功しても） | -1 |
| 仲間や大切な人を傷つける | -2 |
| 攻撃する | 敵対へ |
| 目の前で人を殺す（その場の NPC 全員） | -1 |
- 機嫌を取る判定は、状況が変わらない限り 1 人に 1 回（G7）。新しい材料（贈り物、手柄、新しい話）があればもう一度。

## 3. 秘密と嘘
- 秘密を話してもらうのは「大きな頼み」。話した秘密は、手がかりとして記録する（世界の決まり 5: 手がかり以外の道では知れない）。
- 嘘をつく NPC は、聞かれると嘘を語る。見抜くのは知か心の判定（普通、相手が黒幕なら難しい）。見抜いても分かるのは「嘘だ」ということだけ。

## 4. 仲間の NPC（同行）
- 同行は「大きな頼み」。同行の項目が「喜んで」なら判定なし、「来ない」ならできない（理由を出す）。
- 一行に同時に 2 人まで。画面左の 3 人の下に小さく並べる。
- 戦闘の型（数字はゲームの表）:
  | 型 | HP | 守り | 攻撃のダメージ |
  |---|---|---|---|
  | 弱い | 5 | 10 | 1 |
  | 普通 | 9 | 12 | 2 |
  | 強い | 14 | 13 | 3 |
- 戦闘では、味方の手番の最後にゲームが役目どおりに動かす（攻め = 一番弱った敵を攻撃、守り = HP が一番低い仲間をかばう、癒し = 回復 小）。
- 宣言の中で「〇〇に〜を頼む」と書けば、そちらが優先される。指示は台詞なので手番を使わない（G2 の判定なしの段）。
  仲間の NPC の判定は、指示した人が振る（誰も指示しなければゲームが振る）。
- 探索では、得意な能力値の判定を「手伝う」（+2）。1 手に 1 回。
- HP 0 で倒れる。戦闘の後に運命のダイス（ありそう）で生死を決める。とどめを受ければ死ぬ。
- 態度が中立より下がると去る。
- 裏切り: 引き金が起きたとき、態度が信頼なら裏切らない、友好なら運命のダイス（五分）、それより下なら裏切って敵になる。
- 次の晩へは持ち越さない。記録帳に縁（最後の態度）として残り、酒場で再会できる。縁が友好以上なら判定なしで雇い直せる、中立なら大きな頼み。

## 5. 敵と NPC の入れ替わり
- どの NPC も戦闘の型を持つので、攻撃すればその場で敵になる（態度は敵対、立ち絵はそのまま）。
- 降伏した敵・捕まえた敵は NPC になる（態度は敵対。命を助けたなら +2 で中立）。尋問は「普通の頼み」。

## 6. その場で生まれる NPC
- 設定表にいない人（「その辺の村人に聞く」）は、AI がツールで足す: 役は端役、態度は中立、型は弱い、立ち絵は一覧から。
- 端役は設定表の秘密を知らない。噂は運命のダイスで決めて事実メモに残す。
- 1 晩に 8 人まで。足した人は以後、設定表の NPC と同じに扱う（仲間にもできる）。

## 7. 時計（NPC が自分から動く。2026-10-19 に洗い直し。見せ方は決定、数字は案）
物語の中の時間で、NPC や黒幕の企みが進む仕組み。NPC ごとの予定も、黒幕の儀式も、すべて「時計」1 つの仕組みで表す。

### 洗い出した穴と手当て
| 穴 | 手当て |
|---|---|
| 時計の名前が見えると秘密が漏れる（「伯爵の儀式」で黒幕が分かる） | 時計は冒険者がその危険を知ったときから見える。表の名前（「娘たちの眠り」）と裏の名前を分ける。知るまでは兆しだけ |
| 「手」の数え方が曖昧。戦闘は 1 回で 5 手番進む | 数えるのは全員の宣言がそろった探索の手だけ。戦闘は 1 回で 1 手と数える。分かれて行動中も全体で 1 つ |
| 1 晩の手数（探索 50〜60 手の見込み）に対して速すぎる・遅すぎる | 時計ごとに速さを決める（速い = 3 手、普通 = 5 手、遅い = 8 手ごとに +1） |
| 幕 1 の追っ手が幕 3 まで動き続ける | 時計ごとに動く幕を決める（幕 1 だけ、など） |
| 「企む者に気付かれる」が AI の気分になる | 忍ぶ・騙す判定の失敗か大失敗のときだけ選べる |
| 戻す方法の繰り返し | 1 つの時計につき、同じ戻し方は 1 回だけ（G7） |
| 戦闘中に満ちて「敵が現れる」 | 戦闘中に満ちたら、戦闘の後に起きる |
| 満ちて物語が詰む（黒幕が消える、手がかりの持ち主が死ぬ） | 満ちても結末への道は残す: 黒幕は最後の場所を変えて待つ、死んだ NPC は引き継ぎ役（G12）へ |
| 2 つが同時に満ちる | 設定表の順に起きる |

### 仕組み（洗い直した版）
- 設定表に時計を 2〜3 個: 表の名前・裏の名前、目盛り（4〜8）、速さ、動く幕、満ちたら起きること、戻す方法。
- 進むとき（AI は理由を選ぶだけ、目盛りの数はゲームが決める）
  | 理由 | 進み |
  |---|---|
  | 速さの手数が経つごと | +1（ゲームが自動で） |
  | 休む・野営 | +2 |
  | 一晩かけた調べ物など、時間をかける行動 | +1 |
  | 騒ぎを起こす・判定の大失敗 | +1 |
  | 忍ぶ・騙す判定に失敗して、企む者に気付かれる | +1 |
- 戻すとき: 設定表の戻し方に当たる行動に成功したら -2（同じ戻し方は 1 回）。
- 満ちたら（決まった一覧から設定表で選ぶ）: NPC が別の場所へ移る / NPC が死ぬ / 敵が現れる / 場所が変わる（燃える、閉ざされる）/
  黒幕が最後の場所を変える / 結末が 1 段苦くなる。
- 見せ方（決定）: 冒険者がその危険を知ったら、画面の上に表の名前と目盛りの円で出す。知る前は出さず、半分を超えたら AI が兆しを必ず語る。
- 現実の時間の制限はなくした。物語を前へ押すのは時計。

## 8. 評判 → 噂と因縁（2026-10-20 決定: この「B」だけで始める）
比べた案（A 引き継がない / B 話だけ / C〜F 数字 / G 称号 / H 掲示板 / I 翌晩だけの名声）から B を選んだ。
物足りなければ、E（キャラクターごとの評判を、頼みごとをした人の判定に ±1 段で効かせる形）を後から足す。
数字の評判はやめる（オーナー: 数字で引き継ぐとループに陥りそう。嫌われる → 敵に選ばれる → 殺す → もっと嫌われる）。
行いは「話」としてだけ次の晩へ残す。考え方は能力値・装備と同じ「強さはその晩のもの、持ち越すのは歴史」。

### 残すもの（晩の終わりに作る）
- **噂**（1〜2 行）: 世間がその晩の一行について話すこと。例「眠る竜亭の連中が、ヘザー村の騎士を鎮めたそうだ」。
- **因縁**（0〜2 件）: 次の晩以降の物語の種。種類は決まった一覧から: 逃がした敵 / 交わした約束 / 恨みを買った / 恩を売った / 解けずに残った謎。
  - 候補はゲームが晩の状態から出す（生き延びた敵対の NPC、信頼まで上がった NPC、逃げた黒幕、満ちずに残った時計など）。
    AI はその中から選んで 1 行で書くだけ。
- 晩の終わりに AI を 1 回呼ぶ（語り部の締めの語りと一緒に）。保存は記録帳（`chronicle.json`）に足す。

### 使い方
- **物語づくり**: 決着していない因縁から 1 晩に 1 つまでゲームが選び、物語を作る AI に「味付け（脇役かひねり。本筋や黒幕にはしない）」として渡す。
  その晩の参加者が関わった因縁を優先する。
- **NPC の台詞**: 直近 3 晩の噂を語り部に渡す。NPC は台詞で触れてよい（「あんたら、騎士を鎮めた連中か」）。
- **数字は変えない**: 噂や因縁で、態度・判定・敵の強さは変わらない。

### ループの歯止め
- 因縁は 1 晩に 1 つまで、味付けとしてだけ。
- 一度物語に出した因縁は決着済みにして、二度と使わない。
- 使われないまま 3 晩たった因縁は消える。
- 噂は直近 3 晩分だけ。
- 新しく入った人は、噂で語られることはあっても、数字で不利にならない。

### 画面
- 記録帳: 晩ごとの頁に「噂」と「残った因縁」（決着済みには印）。
- 酒場の画面: 掲示板に最近の噂を 1〜2 行。
- 因縁がその晩に使われることは、始まる前には出さない（現れたときの驚きのため）。

### 晩の中のこと（変わらない）
- NPC 1 人ひとりの態度（5 段）。目の前で人を殺すと、その場の NPC 全員 -1。

### やめたもの
- 勢力ごとの評判の数字、NPC の勢力の欄、評判による態度のずれ、評判を物語のくじに混ぜること。

## 9. 話が止まったときの手助け（2026-10-19、この形で試して様子を見る）
今は AI への指示に「冒険者が迷っていそうなら、NPC の台詞や気付きの形で手がかりを出す」の 1 行だけ。
いつ・何を・どこまで出すかを AI が決めるので、早すぎたり、手がかりの文（「騎士の名はバルドリック。名を呼べば剣を止める」）を
そのまま言ってしまったりしうる。→ **止まったかどうか、どの手がかりを、どの段まで出すかはゲームが決め、AI は言い方だけを担う。**

- 決まり: ヒントは手がかりの「ありか」を指すだけで、手がかりそのものは渡さない。手に入れるのは必ず冒険者の行動（行く・聞く・調べる・判定）。
- 止まったと見なす: 新しい手がかり・新しい場所・幕の進み・戦闘のどれも起きない手が続いたとき（ゲームが数える）。
  どれかが起きたら数え直す。
- 段（2026-10-23 変更: 文は手で書かない。ゲームが「ありか（どこ・誰）」を渡し、AI が段に合わせて言い回しを作る。下の例は言い回しの見本）
  | 段 | 中身 | 例（灰色の森の祠「騎士の名」） |
  |---|---|---|
  | 1 気配 | 手がかりのある方角・場所・人を、ほのめかす | 村の子ども「森の小屋のおじいちゃん、昔の騎士さまのお話ばっかりするの」 |
  | 2 糸口 | 手がかりを持つ場所や人を名指しする | 村長「騎士の墓のことなら森の狩人に聞け。あれの祖父が墓守だった」 |
  | 3 助け舟 | 手がかりを持つ人が向こうから来る・物が目の前に現れる。聞き出すのは判定 | 狩人が自分から村へ下りてきて、一行に声をかける |
- どの手がかりか: 今の幕で、まだ見つけていない手がかりのうち、今いる場所から一番近いもの（ゲームが選ぶ）。
- 出し方の型（AI が選ぶ）: NPC の噂話・台詞 / 目に入る物（煙、足跡、落とし物）/ 物音や匂い。
  冒険者の気持ちや「ふと思い出す」は使わない（冒険者の心を GM が決めない決まり）。
- 手数の目安（語り部の性格で変わる）
  | 語り部 | 段 1 まで | 段 2 まで | 段 3 まで |
  |---|---|---|---|
  | オルウェン（標準） | 4 手 | +3 手 | +3 手 |
  | マルタ（助言が多い） | 3 手 | +2 手 | +2 手 |
  | ブラム（助言が少ない） | 6 手 | +4 手 | 出さない |
  | ヴェイル（不穏） | 4 手 | +3 手 | +3 手（言い方が不穏） |
- AI への渡し方: ヒントを出す手だけ「【手助け】段 1: （段 1 の文）。この語りの中に、出し方の型のどれかで織り込む」を足す。
  それ以外の手では「自分からヒントを出さない」と指示する（今の 1 行は消す）。
- 語り部への注文欄に「手がかりがほしい」を置く。押すと、次の手で段が 1 つ上がる。
- 止まっている間は時計も進む（手が 4 つ進むごとに +1）。ヒントと危険が同時に近づく。
