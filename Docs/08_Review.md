  まとめて 1 回の語り直しに。内緒の語りは語りの呼び出しで一緒に返す。枠の残りが少ないと語り直しを止める。

### B4 の決定: ゲームが判定できる条件（2026-10-22）
- 条件は「全部そろったら」の形で、型は 6 つ。
  | 型 | 中身 |
  |---|---|
  | 人物 | 生きている / 倒れた / 眠った / 退いた / 一行と一緒 / どこにいる / 態度。敵と生き物（子トロルなど）も人物として扱う |
  | 物 | どこにある / 誰が持つ（冒険者・NPC）/ 種類と数（宝を 1 つ以上） |
  | 場所 | 一行（または誰か）がどこにいる |
  | 出来事 | ゲームが立てる印（下） |
  | 時計 | 満ちた / 満ちていない / 目盛りがいくつ以上 |
  | 確信 | どの結論に確信したか |
  「どれか 1 つ」は、解き方や目的を複数書いて表す。
- **出来事はなるべくゲームが立てる**: 物語に「仕掛け」（場所・要る判定・成功で立つ出来事）を置く（例: 水門 / 回廊 / STR 普通 / 「水門を開けた」）。
  AI は仕分けで、その場所の仕掛けの一覧から選ぶだけ。サイコロはゲームが振り、成功したらゲームが出来事を立てる。
  ボスを倒した・場所に着いた、などはゲームがもともと知っている。
- **物の受け渡しはゲームが確かめる**: 物を置く・渡す宣言は、仕分けの段で「持っているか」「その場所にいるか」をゲームが確かめる。
  足りなければ「できない（持っていない）」。語りの前に確かめるので、語りと状態が食い違わない。
- 物と人物には設定表で id を振り、AI には id で返させる（名前の揺れを防ぐ）。
- **想定外の解き方**（案 b）: 手で書いていない解き方には、AI が判定（至難 19）を付ける。成功すれば、ボスの状態を「退いた」「眠った」などに変えられる。
  1 物語に 1 回まで。結末は解き方ではなく状態で判定するので、想定外の解き方でも正しく決まる。
- ハンドアウトの個人の目的も、手で書いた候補（条件付き）から AI が選ぶ。

### C1 の決定: AI の仕事を 2 回の呼び出しに分ける（2026-10-22）
- **1 回目: 仕分け**（いつも Flash-Lite）。宣言ごとに返す:
  段に分ける（複数の行動）/ 段ごとに そのまま成功・判定・できない・運命のダイス /
  判定なら 能力値・難しさ・段をずらす理由（不得意・有利・不利・なし）/ できないなら 理由（3 種類）とどうすればできるか /
  向け先の id（仕掛け・物と動かす先・人物と頼みの大きさ・手がかり）。判定なしの段にも手がかりの id を付ける /
  効果の種類と大きさ（技・呪文・戦闘の自由な行動）/ 大事な判定なら、失敗したときの代償（先に決める）/
  推理なら どの結論か・合っているか / 想定外の解き方なら至難の印。
- **2 回目: 語り**（ボスの登場と結末だけ 3.8 Flash、ほかは Flash-Lite）。返す:
  表の語り / 内緒の行動をした人だけの語り / 小さな付け足し（事実メモ、端役、小さな物（名品は不可）、態度が変わった理由（一覧から））。
- **ゲームが決める**: サイコロ、対抗判定の検出（向け先の id を見比べる）、内緒の見つかる判定、名付けた技の検出（【】を読む）、
  複数の行動の上限、代償の当てはめ、手がかりの記録、時計、ヒント、場面の種類（人物に向けた段があれば会話）、緊迫、幕、結末、物の受け渡しの確かめ、
  語りの見張り（名前の抜け・ゲームの言葉・内緒の漏れ）。
- **壊れた返事**: 抜けた宣言は「そのまま成功（向け先なし）」、知らない id は捨てる。読めなければ 1 回だけ頼み直す（語り直しの枠を使う）。
- **手元の AI のとき**: 仕分けを縮めた形（段・能力値・難しさだけ）にする。推理・仕掛け・受け渡しの確かめはその間は止まる。
- **宣言にない冒険者の動き**は、プログラムでは見分けられないので、指示文で強く言うだけにする（ゲームの見張りからは外す）。
- **進め方**: 実装の最初に、画面を作らずボット（Tavern.Cli）でこの 2 回の呼び出しだけを作り、意地悪な台本で試す
  （できない、運命のダイス、ぶつかる宣言、内緒、推理、複数の行動、名付けた技、仕掛け、受け渡し…）。
  仕分けが 9 割以上正しければ先へ。届かなければ仕分けを割るか欄を減らす。Flash-Lite と手元の AI の両方で、1 手の呼び出し回数と待ち時間も測る。
  試験には試験用のキー（R3）を使う。キーが用意できるまでは、手元の AI での試験と台本づくりを先に進める。
