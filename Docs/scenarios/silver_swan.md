# 銀の白鳥号の歌（新しい形、2026-10-21 下書き）

## 基本
- 場所（地方の地図）: 嘆きの浜辺。起点は漁村ソルトホロウ。
- 型: 難破船。闇の深さ: 中。
- 導入: 嵐の夜、浜に古い帆船が打ち上げられた。船首には、五十年前に消えた王都の商船「銀の白鳥号」の名。それから毎晩、沖から女の歌声のような音が聞こえ、漁に出た船が戻らない。老水夫ハーランが眠る竜亭に来る。報酬は銀貨 35 枚と、腕のいい船。
- 目的: 沖の歌を止め、ソルトホロウの船が海へ出られるようにする。
- 失いうるもの（★ = 重い）: ★戻らない漁師たちの命、★冒険者の命、女傭兵カイラの命、海の真珠、老水夫ハーランの船。

## 真相（プレイヤーには秘密）
白鳥号の積み荷「海の真珠」は、深海の大蛇の心臓のかけら。五十年前、王家への献上品として真珠を奪った白鳥号は、大蛇に沈められた。
嵐で船が打ち上げられると、網元ヴィクターが真珠を見つけ、海の洞窟に隠した。王都の商人に売るつもりでいる。
大蛇は真珠を呼んで沖で歌い、嵐と波で村を脅かしている。戻らない漁師たちは、沖の岩場の洞に打ち上げられて、まだ生きている。
真珠を海へ返せば、大蛇は鎮まる。

## ハンドアウト用の断片（4 つ）
- 五十年前、王家に献上されるはずだった「青い宝」が届かなかった、という話を王都で聞いた。
- ソルトホロウの網元は、近ごろ王都の商人と手紙をやりとりしているらしい。
- 船乗りの迷信: 歌う海には、光を向けよ。
- 白鳥号の見習い水夫で、ただ一人生き残った少年がいたという。

## 山場: 沖の岩場
1. **倒す**: 大蛇との戦い。灯台に火がともっていれば、大蛇の攻撃をかわす判定 +2。
2. **真珠を返す**: 真珠を海へ投げ返す（大蛇の近くまで寄る必要がある。AGI 普通）。大蛇は真珠を飲み込み、歌をやめて沈む。
3. **漁師を連れて逃げる**: 岩の洞の漁師たちを連れて、潮が満ちる前に浜へ戻る。歌は止まらない（失敗。ただし漁師は救える）。

## 選択の山場
真珠は王都で城が買えるほどの値。ヴィクターは「三人で分けよう」と持ちかける。返せば海は鎮まるが、ソルトホロウは貧しいまま。

## 結末の骨組み
- 成功: 歌が止み、漁師たちは戻り、誰も失わなかった。真珠を返したなら海は穏やかになり、倒したなら沖に大蛇の骨が残る。
- 苦い成功: 歌は止んだが、漁師か仲間を失った。
- 失敗: 歌は今も続いている。
