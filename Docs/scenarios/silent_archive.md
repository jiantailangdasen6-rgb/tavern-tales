# 沈黙の書庫（新、2026-10-21 下書き）

## 基本
- 場所（地方の地図）: 古の都の遺跡。滅びた魔導王国の神殿の地下。
- 型: 遺跡の探索。闇の深さ: 中。
- 導入: 王都の学者マティアスが眠る竜亭に来る。「古の都の神殿の床が崩れ、地下に書庫の入口が見つかった。魔導王国が最後に封じた『沈黙の書』があるはずだ。中を確かめたい。だが、銀枝会の連中も嗅ぎつけた。先を越されたくない」。報酬は銀貨 45 枚と、書庫で見つけた写本の写し。
- 目的: 銀枝会より先に書庫の奥へ着き、沈黙の書を確かめる（封じるか持ち帰るかは、着いてから決める）。
- 失いうるもの（★ = 重い）: ★冒険者の命、★学者マティアスの命、銀枝会の魔術師ヘルガの命、冒険者の「声」（大失敗の代償）、沈黙の書。
- 書庫の中では声を立ててはいけない。話す・叫ぶ・呪文を唱えると、書庫が目覚める。

## 真相（プレイヤーには秘密）
沈黙の書は、読んだ者の言葉を吸い取り、その人が知っていることを書の中に移してしまう魔導書。魔導王国はこれで敵国の学者たちの知恵を奪い、最後には自分たちの言葉まで吸い尽くされて滅んだ。
最後の司書オルテアは、書を封じるために書庫ごと眠りにつき、亡霊となって今も書を守っている。書庫の「静けさの掟」は、書が人の声を吸い寄せるのを防ぐためのもの。
銀枝会の魔術師ヘルガは、書を使って王都の魔術師たちの知恵を奪い、学院の長になるつもりでいる。
マティアスは純粋な学者だが、書を持ち帰れば名を上げられると、心が揺れている。

## ハンドアウト用の断片（4 つ）
- 魔導王国は、戦ではなく「沈黙」によって滅んだ、という説がある。
- 銀枝会の魔術師ヘルガは、学院の長の座を狙っていると噂される。
- 古い司書たちは、口を使わない言葉を持っていたらしい。
- 遺跡の盗掘者の間で、「地下の本を読んだ男が、名前も言えなくなって帰ってきた」という話がある。

## 山場: 書の間
書の間では、声を出せない。宣言は動きと手振りだけ（語りもそれに合わせる）。
1. **封じ直す**: 司書の手振りの祈りをまね（MND 普通）、オルテアと共に書を鎖で閉じる。オルテアは安らかに消える。
2. **持ち帰る**: 書を布で包んで持ち出す（DEX 難しい。失敗すると書が開き、触れた者が言葉を少し失う = 大失敗の代償）。マティアスは名を上げるが、書は世に出る。
3. **戦う**: オルテアを倒す（ただし声を出すと書が目覚めて、亡霊が強くなる）。書は誰の手にも渡せる状態で残る。
4. **ヘルガを止める**: ヘルガが先に着いて書を開いていたら、書から引き剥がす（STR 対抗の形）。ヘルガは助かるが、言葉の一部を失う。

## 選択の山場
持ち帰れば、マティアスの研究は進み、王都の学院が書を管理する（はず）。封じれば、書のことは誰も知らないまま。マティアスは「せめて写しだけでも」と頼む。写しを取ると、写した者が言葉を一つ失う。

- 緊迫の場所: 静寂の書架。

## 結末の骨組み
- 成功: 銀枝会より先に書を確かめ、誰も失わなかった。封じたならオルテアは眠り、持ち帰ったなら王都に新しい噂が立つ。
- 苦い成功: 書は確かめたが、マティアスか仲間を失った。
- 失敗: 書は銀枝会の手に渡った。
