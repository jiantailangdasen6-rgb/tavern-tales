# 冬の砦（新、2026-10-21 下書き）

## 基本
- 場所（地方の地図）: 鉄牙山脈。山道の古い砦「鷲の巣砦」。
- 型: 防衛。闇の深さ: 中。
- 導入: 雪の峠を越えてきた伝令が眠る竜亭に駆け込む。「鷲の巣砦に、山賊の頭目ゴルムの一味と、山のトロルが迫っている。砦には若い騎士と、逃げ込んだ村人しかいない。援軍は明日の夜明けに着く。それまで持ちこたえる腕が要る」。報酬は辺境伯からの銀貨 50 枚。
- 目的: 夜明けまで砦を守り、村人を守り抜く。
- 失いうるもの（★ = 重い）: ★村人の命、★若い騎士エドガーの命、★冒険者の命、砦の門、砦の地下の古い宝。
- 前半（第 1・2 幕）で備え、後半（第 3 幕）で迎え撃つ。

## 真相（プレイヤーには秘密）
頭目ゴルムの狙いは村人ではなく、砦の地下に眠る、昔の山の王の宝（金の冠）。古い言い伝えで知った。
砦の傭兵ラースは、借金のかたにゴルムと通じていて、襲撃の夜に裏門の閂を外す手はずになっている。
山のトロルは、ゴルムが子トロルを人質に取って従わせている。子トロルは山賊の野営地の檻の中。子を取り戻せば、トロルは山へ帰る。

## 備え（第 1・2 幕でできること）
一つの備えに、一手と、判定か材料を使う。備えは第 3 幕の戦いを楽にする。
- 門を補強する（STR 普通、材木）: 門への攻撃が 1 回分止まる。
- 罠を仕掛ける（DEX 普通、縄か油）: 最初の手番、敵 1 体の動きを止める。
- 村人を弓兵に仕立てる（MND 普通）: 戦いの毎手番、敵 1 体に 1 ダメージ。
- 偽の灯りを灯す（INT 普通）: 「襲撃」-2。
- 鍛冶屋グンナに武器を直させる（頼みごと）: 誰か 1 人の武器が良い品になる（この晩だけ）。

## ハンドアウト用の断片（4 つ）
- 鉄牙山脈には、山の王の金の冠が眠っているという古い歌がある。
- 山賊の頭目ゴルムは、借金で首が回らない者を手下に引き入れるのがうまいと聞く。
- トロルは子をとても大事にする。子を奪われたトロルは、山を下りてでも取り返そうとする。
- 鷲の巣砦は、もとは砦ではなく墓守の館だったらしい。

## 山場: 夜の戦い（第 3 幕）
戦いは「夜明け」が満ちるまで続く。波のように来る（山賊の第一波 → 裏門 → トロルと頭目）。**緊迫の場所**は中庭（第 3 幕の始まり）。
1. **夜明けまで持ちこたえる**: 援軍が着けば勝ち。
2. **頭目を討つ**: 頭目ゴルム（山賊の頭目、ボス）を倒せば、山賊は散る。
3. **子トロルを返す**: 野営地の檻から子を取り戻し（第 2 幕でも可）、トロルに返せば、トロルは山へ帰る。頭目は一人で戦うことになる。
4. **抜け道から村人を逃がす**: 村人を地下の抜け道から山の外へ逃がせば、守るものは砦だけになる（砦の門は失う）。

## 選択の山場
頭目の狙いの金の冠。地下の墓から持ち出せば、村人を逃がす時間も、借金に苦しむラースを救う金も手に入る。だが、墓を荒らせば、山の王の眠りが……（何が起きるかは書かない。荒らしたら、次の晩の因縁にする）。

## 緊迫の場所・因縁の差し込み口
- 緊迫の場所: 砦の中庭（第 3 幕の始まり）。
- 因縁の差し込み口: 「頭目の客分」。前の晩に逃がした敵がいれば、ゴルムに雇われた客分として第 3 幕に現れる。

## 結末の骨組み
- 成功: 夜明けを迎え、誰も失わなかった。子トロルを返したなら山に親子の声が響き、頭目を討ったなら山道は静かになる。
- 苦い成功: 砦は守ったが、村人かエドガーか仲間を失った。
- 失敗: 砦は落ちた。
