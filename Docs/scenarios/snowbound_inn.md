# 雪に閉ざされた宿（中編、2026-10-21 下書き）

## 基本
- 場所（地方の地図）: 鉄牙山脈の麓の街道宿「熊の灯」。
- 型: 吹雪の山荘の謎解き（閉じた場所での殺し）。中編（5 幕、中休みあり）。闇の深さ: 中。戦いは少なめ、話と調べが多め。
- 導入: ロウフォードの薬屋が眠る竜亭に来る。「熊の灯の大旦那が胸を患っている。この薬を明日までに届けてほしい。吹雪が来る前に」。報酬は銀貨 30 枚（中編の後半で、宿の主人と辺境伯の使いから礼が加わる）。
- 目的: 宿で起きた殺しの犯人を突き止め、次の殺しを防ぐ。
- 失いうるもの（★ = 重い）: ★宿の娘リーゼの命、★冒険者の命、★宿の大旦那の命（薬が届かなければ）、夜鴉の運び屋ヨナスの命、毛皮商人オットーの命、辺境伯の手紙。

## 真相（プレイヤーには秘密）
十八年前、宿のおかみマレーネは辺境伯の館で女中をしていた。辺境伯の子を身ごもり、館を出て、熊の灯の主人ホルストと結ばれた。娘のリーゼは、自分が辺境伯の子だと知らない。
年老いた辺境伯は、跡継ぎにと考えていた甥レオポルドの野心を恐れ、ひそかに騎士クラウスを使いに出した。手紙には「十八年前、我が館の女中マレーネが産んだ子を捜し、守れ」とある。
レオポルドはそれを嗅ぎつけ、配下の暗殺者フィンを吟遊詩人に仕立てて、使いの後を追わせた。
吹雪の夜、フィンは厨房で手を温めるふりをして、温めた葡萄酒の壺に毒草「雪苔」を入れた。その葡萄酒は、何も知らないリーゼがクラウスの部屋へ運んだ。クラウスは閂をかけて眠り、そのまま息絶えた。
夜中、夜鴉の運び屋ヨナスは金目のものを探して、窓からクラウスの部屋に忍び込んだ。クラウスは既に死んでいた。ヨナスは手紙を盗み、怖くなって黙っている。
フィンは手紙がないことに気付き、娘が誰かを探っている。手紙を読めば、次に狙うのはリーゼ。

## 山場: 吹雪の終わり
犯人を暴いたとき、または「吹雪の終わり」が満ちたとき、フィンはリーゼを連れ去ろうとする（リーゼのそばに誰かいれば、その場で戦い）。連れ去られたら、凍った湖を渡って古い見張り塔へ追う。
1. **暴いて捕まえる**: 皆の前で証拠を並べて突きつける（突きつけに判定はない。確信した結論が多いほど、語りでフィンが追い詰められる）。フィンは逃げようとする → 戦いか追跡。
2. **人質を取り返す**: 見張り塔でフィンからリーゼを取り返す（説得 MND 難しい、または戦い）。
3. **吹雪の中の追跡**: 凍った湖を渡る（AGI 普通。失敗すると氷が割れて傷）。塔の上でフィン（暗殺者、ボス）と戦う。

## 選択の山場
手紙をどうするか。
- **リーゼに渡す**: リーゼは自分の出自を知る。辺境伯のもとへ行けば、ヴァルデン家の跡継ぎ争いに巻き込まれる。
- **焼く**: リーゼは宿の娘のまま。甥の狙いも消える（はず）。辺境伯の最後の願いは届かない。
- **辺境伯の使いとして届ける**: 冒険者が手紙を王都へ届ける（次の晩の因縁）。

## 結末の骨組み
- 成功: 犯人を突き止め、リーゼを守り、誰も失わなかった。手紙の行方で、ヴァルデン家の明日が変わる。
- 苦い成功: 犯人は突き止めたが、リーゼか大旦那か仲間を失った。
- 失敗: 犯人に逃げられたか、リーゼを奪われた。
