# 酒場の語り部 (tavern-tales)

An AI game-master tabletop RPG for one to four friends: sword-and-sorcery fantasy, played over one evening,
narrated by a tavern storyteller. Unity 6 / C#. The host plays on Windows; friends join on Windows or in the browser
(https://jiantailangdasen6-rgb.github.io/tavern-tales/).

Non-commercial hobby project. Design notes (Japanese) are in `Docs/`.

**Spoiler warning / ネタバレ注意**: these hold the truths, clues, culprits and solutions of every story:
`Docs/scenarios/`, the story sheets `Unity/Assets/Resources/Content/Stories/`,
and the bot walkthroughs `Core/Tavern.Cli/bench/*_success.txt`. If you are going to play, please don't read them.

遊ぶ予定の人は、`Docs/scenarios/`、物語の設定表（`Unity/Assets/Resources/Content/Stories/`）、
ボットの筋書き（`Core/Tavern.Cli/bench/*_success.txt`）を読まないでください（真相・犯人・解き方が書いてあります）。

Credits for the music, sounds, fonts and art: `Unity/Assets/Resources/Music/credits.txt` (also shown in the game).
