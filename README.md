# 酒場の語り部 (tavern-tales)

An AI game-master tabletop RPG for one to four friends: sword-and-sorcery fantasy, played over one evening,
narrated by a tavern storyteller. Unity 6 / C#, Windows.

Non-commercial hobby project. Design notes (Japanese) are in `Docs/`.

**Spoiler warning / ネタバレ注意**: `Docs/scenarios/` and the scenario data contain the truths, clues and culprits of every story.
If you are going to play, please don't read them. 遊ぶ予定の人は `Docs/scenarios/` と物語のデータを読まないでください（真相と犯人が書いてあります）。
